7️⃣  IF SOMETHING GOES WRONG
────────────────────────
Browser not opening?
  → Manually go to http://localhost:3000

Changes not showing?
  → Hard refresh: Cmd+Shift+R
  → Check console for errors (F12)

Server crashes?
  → Stop terminal: Ctrl+C
  → Run: npm start again

Need to kill port 3000?
  → lsof -ti:3000 | xargs kill -9
